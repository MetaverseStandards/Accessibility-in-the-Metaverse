Each term has its own permanent link, and points to the WCAG or MSF definition it uses or differs from. See the terms in use on the sample criteria page.

How each term relates to its sources

Adopted
Uses the source's definition as it is.
Adopted with an XR note
Uses the source's definition, plus a note on how it applies in XR.
Differs
Our own draft definition, because the sources' do not fit.
Ours
Our own draft definition, with no equivalent in the sources.

Definitions

application

Relationship: Ours

Draft definition: The software, including its content and interface, that a person uses to take part in an extended reality experience.

Draft note: Our criteria are written about the application. WCAG's user agent is defined around web content, and MSF's browser is defined around X3D files, so neither is the same thing.

Related: WCAG 2.2: user agent; MSF Glossary: browser

Used in: Inclusive Representation, Captions: live content, Caption formatting: size, Caption formatting: contrast, Audio Descriptions: triggered, Assistive Technology Compatibility, Target Size

Link to “application”

assistive technology

Also: assistive technologies, AT

Relationship: Adopted with an XR note

Definition: WCAG 2.2: assistive technology

Draft note: WCAG's definition relies on user agents. Open question: how should it apply when assistive technology is part of a headset's operating system, or built into an application?

Related: WCAG2ICT: applying "user agent" to non-web software

Used in: Assistive Technology Compatibility

Link to “assistive technology”

audio description

Also: audio descriptions

Relationship: Adopted with an XR note

Definition: WCAG 2.2: audio description

Draft note: WCAG's definition is about a soundtrack. An XR application may not have a fixed soundtrack, so a description may be triggered by what a person does or what is near them.

Used in: Audio Descriptions: triggered

Link to “audio description”

avatar

Also: avatars

Relationship: Differs

Draft definition: A representation of a person in a virtual or mixed environment, through which others can perceive them and through which they may act.

Draft note: MSF's definition covers the same idea but is limited to X3D worlds. WCAG 2.2 does not define this term.

Related: MSF Glossary: avatar

Used in: Inclusive Representation

Link to “avatar”

contrast ratio

Relationship: Adopted with an XR note

Definition: WCAG 2.2: contrast ratio

Draft note: Open question: what should be measured when lighting, transparency or a real-world background changes the colors a person sees?

Used in: Caption formatting: contrast

Link to “contrast ratio”

CSS pixel

Also: CSS pixels

Relationship: Adopted with an XR note

Definition: WCAG 2.2: CSS pixel

Draft note: A CSS pixel is a visual angle of about 0.0213 degrees, so 48 CSS pixels is about 1 degree. It is not the same as a pixel of the headset's display or a pixel of an image, so do not write "pixel" without saying which.

Related: MSF Glossary: pixel (element of an image)

Link to “CSS pixel”

degree of visual angle

Also: degree, degrees

Relationship: Ours

Draft definition: A unit for how large something appears to a viewer, based on both its size and its distance.

Draft note: For something viewed straight on: angle = 2 × arctan(size ÷ (2 × distance)).

Draft note: This is the apparent size of one thing. It is not a headset's field of view, which is also given in degrees.

Related: WCAG 2.2: CSS pixel

Used in: Caption formatting: size

Link to “degree of visual angle”

interactive element

Also: interactive elements, user interface component

Relationship: Differs

Draft definition: A part of an application that responds to a person's input, such as a menu button, a slider or an object that can be picked up.

Draft note: WCAG 2.2 calls the nearest idea a user interface component. The WCAG 3.0 draft defines interactive element, and also requires a name that software can determine.

Related: WCAG 2.2: user interface component; WCAG 3.0 Working Draft: interactive element

Link to “interactive element”

live

Relationship: Adopted with an XR note

Definition: WCAG 2.2: live

Draft note: WCAG's definition is about real-world events. Open question: do speech between avatars and events that happen only in a virtual world count as live?

Used in: Captions: live content

Link to “live”

pointer input

Also: pointer

Relationship: Adopted with an XR note

Definition: WCAG 2.2: pointer input

Draft note: WCAG's definition is about coordinates on a screen. In XR, pointer input may also come from a ray, hand, controller or gaze aimed into three-dimensional space.

Draft note: Conflict: in the MSF Glossary, pointer means a location and direction in the virtual world, not the input itself. These guidelines do not use it that way.

Related: MSF Glossary: pointer

Link to “pointer input”

programmatically determined

Also: programmatically determinable

Relationship: Adopted with an XR note

Definition: WCAG 2.2: programmatically determined

Draft note: Open question: which platform accessibility services count for XR, and what applies where a platform does not have one?

Used in: Points of Interest: role

Link to “programmatically determined”

single pointer

Relationship: Adopted with an XR note

Definition: WCAG 2.2: single pointer

Draft note: WCAG's definition is about one point on a page or screen. In XR, this may be one hand, controller, ray or gaze used on its own.

Link to “single pointer”

target

Also: targets, hit target

Relationship: Adopted with an XR note

Definition: WCAG 2.2: target

Draft note: WCAG's definition is about a region of the display. In XR, a target may be a three-dimensional volume whose apparent size changes with distance.

Used in: Target Size

Link to “target”

virtual world

Also: world

Relationship: Differs

Draft definition: A computer-generated environment that a person can perceive and interact with in an application.

Draft note: MSF's definition covers the same idea but is limited to X3D files shown by an X3D browser. WCAG 2.2 does not define this term.

Related: MSF Glossary: world

Link to “virtual world”
