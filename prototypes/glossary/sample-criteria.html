Sample criteria with glossary links

Wording is from the public working document of 20 November 2026, with links added. Each term is linked the first time it appears in a criterion. Back to the glossary.

Inclusive Representation

The application provides user options for a customizable avatar. A wide variety of identities is offered. This includes options for avatar height, body shape, skin color, hair, prosthetic limbs, assistive devices such as hearing aids, and so on.

Captions: live content

The application provides captions for live content, including user-generated speech in a multi-person application.

Caption formatting: size

The application provides text with a minimum cap height of 0.7 degrees. This is a common baseline for readable captions in XR, but the ideal size depends on distance, field of view, and the headset.

Caption formatting: contrast

The application provides captions with a minimum contrast ratio of 4.5:1 in typical viewing conditions. A solid color background is recommended to ensure consistent contrast across different environments.

Audio Descriptions: triggered

Triggered - The application offers audio descriptions for important visual events (e.g. characters entering or leaving, major environmental changes, proximity to interactables).

Points of Interest: role

Spatial elements relevant to navigation have a programmatically-determined role and functional meaning. Relevant elements may include routes, navigation nodes, decision points, obstacles, landmarks, destinations, points of interest, risk zones and system reliability states.

Assistive Technology Compatibility

The application provides compatibility with assistive technologies.

Target Size

The application contains a minimum size of hit targets as 48 x 48 pixels, or approximately 3° FOV.

Open question: 48 CSS pixels is about 1 degree, not 3. The group needs to decide which size was meant. See the glossary entries for CSS pixel and degree of visual angle.
